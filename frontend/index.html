Data Pipeline Architecture

1. Categorical Encoding: OneHotEncoder applied to type (PAYMENT, TRANSFER, CASH_OUT, CASH_IN, DEBIT).
2. Domain-Specific Discrepancy Features: Calculates balance variance formulas to expose spoofed transactions.
3. Feature Normalization: StandardScaler standardizes variables to zero-mean and unit-variance.
4. Imbalanced Class Penalization: Trained with class_weight='balanced' to penalize false negatives severely.
