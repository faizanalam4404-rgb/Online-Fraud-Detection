Mission & Architecture Overview

FraudGuard was engineered to bridge modern cybersecurity with machine learning intelligence for financial institutions, payment gateways, and individual customers worldwide. Our system evaluates online payment transactions in real-time, delivering immediate verdicts, calibrated fraud probabilities, and explainable risk factors.

Rather than treating payment risk as a black box, FraudGuard unpacks every transaction through multi-dimensional feature engineering: checking sender balance depletion continuity, destination mule account footprints, transfer corridor exposure, and temporal variance.

Core Engineering Principles
Customer Isolation
Strict multi-tenant customer isolation at the ORM query level. Customers cannot query, view, or infer other users' transactions.
True Multi-Currency
Never overwrite original payment currencies or amounts. Normalizes to base USD via real exchange rates for model inference while rendering in local currencies.
Transparent MLOps
Distinct separation between offline test benchmark scores (Random Forest 99.82% accuracy) and live streaming production telemetry.
Compliance & Export
Export transaction histories to formatted CSV and official ReportLab PDF statements with cryptographic verification hashes.
System Specifications
  • Backend Framework Python 3.14 / Flask 3.1
  • Database Engine SQLite 3 (PostgreSQL Ready)
  • ML Framework Scikit-learn 1.9 & Polars
  • Model Architecture Random Forest (Balanced)
  • PDF Statement Engine ReportLab 5.1
  • Currencies Supported 60+ ISO 4217 Currencies
