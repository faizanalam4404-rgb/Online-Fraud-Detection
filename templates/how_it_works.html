End-to-End Prediction Lifecycle

When an online payment is submitted, it traverses a structured 5-stage inference pipeline before reaching persistent database storage. This guarantees accurate currency conversion, mathematical feature generation, and calibrated probabilistic risk scoring.

Stage 1: Input Validation & ISO 4217 Currency Conversion

Validates positive payment amounts, balance continuity, and ISO 4217 currency compliance. Converts local currency amounts to base USD using live or cached exchange rates. The original transaction amount and currency code are strictly preserved.

Stage 2: Domain-Engineered Financial Features

Raw parameters are expanded into banking discrepancy indicators designed to detect synthetic and laundering behavior:

  • Origin Discrepancy: errorBalanceOrig = (newbalanceOrig + amount) - oldbalanceOrg (expected 0.0 for honest payments).
  • Destination Discrepancy: errorBalanceDest = (oldbalanceDest + amount) - newbalanceDest.
  • Account Drain Ratio: drainRatio = amount / (oldbalanceOrg + 1.0) (flags sudden liquidation of funds).
  • Zero Destination Mule Flag: Traces recipient accounts that start at $0 and immediately withdraw back to $0.
  • Corridor Rail Risk: TRANSFER and CASH_OUT rails represent 99%+ of historical financial fraud volume.
Stage 3: Pipeline Column Transformation

Transforms the feature row using a fitted Scikit-learn ColumnTransformer. Categorical payment rails are one-hot encoded (handle unknown ignores), while continuous numerical balances and ratios are normalized with StandardScaler.

Stage 4: Ensemble Random Forest Scoring

The champion RandomForestClassifier evaluates the transformed vector across an ensemble of decision trees trained with balanced class weights to conquer financial class imbalance. Produces a consensus classification and calibrated fraud probability.

Stage 5: Risk Tiering & Multi-Factor Audit Explanation

Categorizes the score into risk tiers (LOW <20%, MEDIUM 20-50%, HIGH 50-80%, CRITICAL ≥80%) and generates human-readable cybersecurity explanations for compliance review.
